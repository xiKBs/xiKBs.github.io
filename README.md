# KRISH / Security Research Journal

A responsive, static portfolio and learning-lab site. It uses plain HTML, CSS, and JavaScript, so there is no build step or backend.

Open \`index.html\` directly in a browser, or serve the \`outputs\` folder from any static file server.

Before publishing, update the three placeholder contact links in \`index.html\`:

- \`hello@yourdomain.dev\`
- \`https://github.com/your-handle\`
- \`https://linkedin.com/in/your-handle\`
